# Paper

Source for the preprint accompanying this repository.

## Build

Requires a TeX distribution (TeX Live, MiKTeX, or MacTeX) with `pdflatex` and `bibtex`:

```bash
cd paper
pdflatex overdrive_stability
bibtex overdrive_stability
pdflatex overdrive_stability
pdflatex overdrive_stability
```

Or with `latexmk`:

```bash
latexmk -pdf overdrive_stability.tex
```

## Files

- `overdrive_stability.tex` — main source
- `overdrive_stability.bib` — bibliography
- `figures/`                 — generated by `python ../scripts/benchmark.py` (see top-level README)

## Submission targets

The current `\documentclass` is plain `article`. Conversion to OSA / IEEE
templates requires only swapping the document class and tweaking the title
block. See the OSA `osajnl` class for Optics Letters / Applied Optics, and
`IEEEtran` for IEEE journals.

The benchmark figure is currently commented out in the .tex source — uncomment
the figure environment once you have rendered `figures/benchmark.pdf`.
